2. Touch ID con Secure Enclave

Puente t2-touchid sobre red interna CDC-NCM IPv6 (puerto 59602), enlazando la huella enrolada en macOS con fprintd y PAM para sudo.

3. Debounce & Persistencia

Debouncing de 40 ms para evitar teclas repetidas y servicio systemd que mantiene vivo el enlace tras abrir y cerrar la tapa.
