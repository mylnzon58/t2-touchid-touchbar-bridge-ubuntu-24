⚡ Arquitectura de Comunicación con el Coprocesador Apple T2

En lugar de depender de parches cerrados para una sola distro, este puente conecta el espacio de usuario de Ubuntu directamente con BridgeOS a través del bus de red virtual USB:

⚡ Apple T2 Coprocessor Communication Architecture

Instead of relying on single-distro proprietary recipes, this bridge wires Ubuntu userspace directly to BridgeOS over the virtual USB CDC-NCM bus:

1. Enlace T2 CDC-NCM

Dispositivo USB 05ac:8233 aislado de NetworkManager para evitar desconexiones en suspensión.

2. RemoteXPC Port 59602

Handshake HTTP/2 link-local activo con el Secure Enclave (SEP) en fe80::aede:48ff:fe33:4455.

3. Touch Bar & Teclado

Filtro de debouncing de 40 ms para suprimir dobles pulsaciones en teclados mariposa y atenuación suave.
